QA sim harness — bots play the real game logic at max speed and report pacing / fun / health.

  npm run sim                                  full suite: active,casual,afk × 50,100,200h × 3 seeds
  npm run sim:quick                            smoke test: active × 10h × 1 seed (for CI / npm run release)
  npm run sim -- --profiles=casual --hours=100 --seeds=5

Flags:
  --profiles=a,b     bot profiles (scripts/sim/profiles.js): active, casual, afk
  --hours=50,100     sim horizons; each is a separate fresh run
  --seeds=N          runs per profile×horizon (seeds are deterministic: same seed = same result)
  --seed=N           first seed (default 1)
  --path=founder     founder (leaves sect to found own) | member (stays a sect member forever)
  --set="EXPR"       balance override evaluated after data loads; repeatable. Examples:
                       --set="WAR_MIN_INTERVAL_HOURS=1"
                       --set="CULTIVATION_STAGES[11].qiCap=5000"
                       --set="SECT_FOUNDING.minStage=15"
  --dt=1             seconds per game tick (real game caps at 2)
  --out=DIR          output folder (default scripts/sim/out)
  --quiet            no progress line

Output: <out>/report.md (read this) + <out>/report.json (full per-run detail).
Exit code: 0 healthy, 1 errors/invariant violations found, 2 harness crashed.
